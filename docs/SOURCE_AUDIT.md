## Mathematics
J(S)=E[R(S)]−λC(S)−κV(S) is a declared utility objective, not an empirical improvement theorem.
Möbius interaction Γ is an alternating subset sum. Complete subset support is required.
`stability.finite_difference` implements this operation; `robust_calibration.interaction_certificate`
propagates simultaneous term intervals. Its scope depends on supplied range, sample design,
cost and shift assumptions; it cannot certify omitted interactions. Bootstrap experiment
intervals are descriptive, not replacements for the finite-sample certificate.

For bounded independent measurements in [-1,1], Hoeffding gives
P(|mean−expectation|>r) ≤ 2 exp(−nr²/2). Assigning α/(TKC) to each prespecified
mean yields r=sqrt(2 log(2TKC/α)/n) and union coverage. No channel independence
is required for that union bound. Channel labels and separate seeds do not prove honesty.

Clarification to historical MATHEMATICS_2.4 theorem wording: selection is covered only among
the prespecified means. Optional within-stream sample-size stopping, newly selected candidates,
repeated undeclared looks, or resetting the horizon are NOT covered. Sample counts and the
catalog must be fixed before seeing outcomes, or separately justified conditional bounds used.
The preview API rejects undeclared sample sizes and relies on external protocol commitment.

The current certificate applies to the measured epoch/context only. An expiration timestamp
cannot establish stationarity before expiration. The API requires the same epoch and context
as well as an unexpired time window.

The reference-honesty premise remains external. Shared corruption can pass every corroboration
test. The original all-corrupt regression is preserved. An ALARM rejects joint consistency;
it does not identify the dishonest channel.

## Implementation findings
The historical package `__version__` says 1.0.0 although Stage P manifests say 2.4.0.
Keep this historical artifact intact; use installed distribution metadata (2.4.0rc1) for
the packaging preview. Legacy numeric configuration validation is permissive about some
Python numeric types. The independent API adds strict validation without changing frozen code.
The historical package verifier requires an exact archive inventory, so the Git tree uses
a separate research verifier and retains the original verifier unchanged.
