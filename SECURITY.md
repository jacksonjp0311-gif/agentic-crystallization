# Security and publication

Report suspected vulnerabilities privately to the repository owner through GitHub.
Never attach credentials, raw agent transcripts, or private memory to issues.
Evidence provenance and honesty are external assumptions; hashes detect modification, not truth.
No automatic execution, agent promotion, network access or Pegasus control exists in the evidence API.
Before publication: approve a license, review the sensitive-data report and all HOLDs, and approve release.
Recommend protected main, required CI on supported Python versions, reviewed PRs, no force pushes,
and immutable historical tags. Rules are recommendations until configured and verified.
