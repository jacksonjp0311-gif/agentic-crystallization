# Contributing

Run `./run.ps1 -Action test` and `./run.ps1 -Action verify` before proposing changes.
Historical source, tests, cohorts, negative results and hash manifests are immutable.
New algorithms require new modules, protocols, disjoint development/holdout seeds and measured evidence.
PATCH denotes corrections; MINOR denotes tested capabilities; MAJOR denotes contract changes.
Repository reorganization does not advance the research algorithm version.
The external evidence API is a preview contract and requires review before production use.
Do not submit private transcripts, memory records, credentials or local user paths.
No public contribution or redistribution license has yet been selected.
